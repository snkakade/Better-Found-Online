# iPhone presentation frame

The website uses the detailed Black Titanium iPhone 16 Pro frame distributed by [WithFrame](https://withfra.me/shot/iphone-16-pro), downloaded from its [black-frame source](https://shot.withfra.me/frames/iphone.16.pro/black).

The frame page permits use in personal and commercial projects, and prohibits selling or redistributing the frames as standalone items. This asset is embedded in Better Found Online's website previews. It is not offered as a standalone download.

Local website assets:

- `app/public/assets/devices/iphone-16-pro-black.webp`: lossless 1109 × 2294 version.
- `app/public/assets/devices/iphone-16-pro-black-554.webp`: lossless 554 × 1146 version for smaller displays.

Only format conversion and resizing were applied. The original bezel, side buttons, antenna details, earpiece, camera and sensor rendering are preserved. The website video and decorative iOS status/home areas sit beneath the transparent screen opening. The render overlays them and supplies the hardware contours.

The display clipping polygon is traced from the frame's alpha aperture. Its traced bounding box is (43, 37)–(1065, 2257). A small additional underlap covers antialiasing when the frame is resized. This follows the render's continuous corner shape, preventing blue gaps between the display and the hardware.
