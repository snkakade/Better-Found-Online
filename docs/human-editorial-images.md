# Human editorial imagery

Ten illustrative working scenes generated with the built-in image tool. These are photography-style illustrations, not photographs of Better Found Online staff, clients or delivered projects. Existing project footage and reports remain the portfolio evidence.

The final prompt for each image is recorded in [human-editorial-image-prompts.json](human-editorial-image-prompts.json).

Optimized website assets are in `app/public/assets/editorial/`, each with a 1440 × 960 WebP and a 720 × 480 mobile WebP. The ten images and their mobile variants total approximately 1.6 MB.

| File prefix | Main placement |
| --- | --- |
| human-creative-shoot | Creative hero and Create service card |
| human-edit-review | Video editing service and creative transition |
| human-website-workshop | Homepage, website service cards and Work collage |
| human-campaign-review | Growth cards and campaign planning |
| human-customer-followup | Integrations, enquiry follow-up and social management |
| human-report-review | Analytics and optimization |
| human-storyboard-session | Motion design and creative planning |
| human-print-check | Graphic design and print production |
| human-social-filming | Social content production |
| human-product-set | Product production and creative transition |

The homepage tunnel keeps its animation and uses the new photographs on its passing cards. The original burgundy files remain unreferenced in the asset archive; protected legacy scrub scenes are unchanged.
